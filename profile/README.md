# opageo

**Open geospatial tools for Earth Observation**

We build open-source pipelines and libraries for working with satellite data —
from data ingestion and harmonisation to machine learning–ready archives.
Simple to install, simple to use, with interfaces that don't get in your way.

---

### What we work on

🛰️ Multi-source satellite data pipelines  
🌊 Flood inundation monitoring  
🌿 Land cover & vegetation modelling  
📦 ML-ready geospatial archives  
🖥️ Beautiful TUIs, web dashboards, and interactive tools
